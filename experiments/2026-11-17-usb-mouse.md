# USB 鼠标应用：构建与设备启动

日期：2026-11-17。设备为 ESP32-P4 v3.2；ESP-IDF 5.5.4 固件新增原生 USB HID 五键鼠标应用。应用管理、鼠标并击和摇杆输出、摇杆校准及触控解析的主机测试通过。固件构建成功，内存统计工具仍报告此前已有的 `cannot assign memory region sram_seg to chip memory type` 警告。

通过 USB-UART 读取分区表，确认与构建配置一致，factory 应用位于 `0x10000`，大小 1 MiB。仅更新该应用区域；esptool 使用 `--no-stub` 并报告数据哈希校验成功。应用镜像 345456 字节，SHA-256 为 `5965deea8a7df468f7def32f159ef8eb03790f66b008b579e08c77ae8749311f`，镜像芯片版本范围 v3.0–v3.99。

重启串口日志显示 PSRAM 内存测试、CST826 触控、显示和摇杆中心校准成功，观测窗口 ADC 错误数为 0；记录到三键选择器选中并进入 `MOUSE`。USB PHY 提示使用 UTMI PHY。当前观察通过 USB-UART，未验证原生 USB 枚举、鼠标各项实际操作、休眠唤醒或长时间运行。

## USB-UART 与 Mac 桥接实测

同日增加串口鼠标报告与 Mac 桥接程序，用户无需切换跳线。更新后的应用镜像 345600 字节，SHA-256 为 `3eb86b051a469a1f1060c92894e15a7c76ea89187d0058e55e8afd2a3578f049`；仅更新 factory 应用区域，esptool 报告写入数据哈希校验成功。桥接程序将串口鼠标报告转换为 macOS 鼠标和滚轮事件；模拟串口测试覆盖 CRLF 报告解析。

用户在当前 Mac 上确认光标、左右键、滚轮及浏览器返回/前进均正常。桥接程序须保持运行；原生 USB HID 枚举、其他电脑与系统、重连及长时间运行尚未验证。
