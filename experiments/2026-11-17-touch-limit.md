# 触控上限：首次实机测试

日期：2026-11-17。设备为 ESP32-P4 v3.2、CST826，芯片 ID `0x11`、I2C 地址 `0x38`。使用独立诊断固件约每 20 ms 从寄存器 `0x02` 起读取 13 字节，保留报告的触点数和原始数据；最多尝试解析并绘制两个坐标。屏幕与固件不提供第三个坐标槽位，因此即使未来报告数超过 2，也不能凭本程序判断第三个坐标是否有效。

## 观察

- 单指操作能报告有效坐标。两指相距较远同时按住并移动时，设备连续报告 `reported=2 valid=2`，原始记录中两个触点的跟踪 ID 分别为 0 和 1；用户确认看到了两个圆圈。例如一次报告为 `028143007000008171120b0000`，解码的两个屏幕位置为 `(527,323)` 和 `(116,369)`。
- 用户单独进行三指分开同时按住约 5 秒的测试，反馈屏幕显示 `COUNT 2、VALID 2、MAX 2`；监测期间报告的最大触点数为 2。本次观察说明这台设备在当前配置及测试条件下能够同时报告两点，三指操作未观察到第三个报告；不是对其他条件或屏幕的全面证明。
- 第一轮测试发现边缘有时报告物理 X=480，初版以像素最大值 479 为界而丢弃该坐标。后续修改为接受包含 480 和 640 在内的理论边界值并映射到末行／列，超出边界的坐标仍丢弃；其中 X=480 有实测记录，Y=640 为防御性处理；包含两点、抬起、越界和边界值的主机解析测试已通过。
- 触点圆圈已改为叠加在原来的按键／摇杆界面，触点数量、有效坐标数和最大报告数在右上角显示。用户反馈双指拖拽靠近边缘时，一个圆圈可能消失，另一圆圈会向其方向偏移，即使该手指未移动。
- 针对边缘现象增加有效触点数变化日志后，捕获到原始数据：如 `0280d5015d0000412410020000` 中，报告数为 2，但第二个点的事件位为抬起，因此有效数为 1；约 20 ms 后读取到 `0180d5015d0000ffffffffffff`，报告数变为 1。用户确认看到圆圈消失时计数变成 1。记录可证明圆圈消失对应原始触控报告的变化，不能单凭本次实验判定传感器、接触情况或控制器算法各自的责任。程序不在点已消失时虚构坐标。
- 观察到的 I2C 读取错误数为 0。这不是触控延迟、坐标准确度、长期稳定性或所有手指组合的完整测试。

[CST826 数据手册](https://surenoo.tech/download/04_STP/Controller/CST826.pdf)提到双点能力，具体模组和控制器固件仍需结合实测判断。本测试没有修改触控控制器配置或升级其固件。上游触控驱动只将单点交给应用，当前诊断固件则保留两个记录并报告原始字节。
